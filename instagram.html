تهيئة Meta لأول مرة

أنشئي تطبيقاً في Meta for Developers وأضيفي منتج Instagram مع إعداد API setup with Instagram Login. استخدمي Instagram App ID وInstagram App Secret، وليس رمزاً مكتوباً داخل الصفحة.

1. إعداد التطبيقفي Meta for Developers، أضيفي Instagram ثم Instagram Login، واجعلي التطبيق في وضع التطوير أثناء الاختبار.
2. عنوان العودة OAuth Redirect URIانسخي العنوان أدناه وأضيفيه كما هو في إعدادات Business Login في Meta، ثم خزّنيه في Netlify باسم INSTAGRAM_REDIRECT_URI.
3. متغيرات Netlify السريةأضيفي INSTAGRAM_APP_ID وINSTAGRAM_APP_SECRET وINSTAGRAM_REDIRECT_URI وADMIN_SESSION_SECRET في Environment Variables. لا تضعي App Secret أو Access Token في ملفات GitHub.
التخزين السحابي للصور والفيديوأنشئي حساب Cloudinary ثم أضيفي CLOUDINARY_CLOUD_NAME وCLOUDINARY_API_KEY وCLOUDINARY_API_SECRET إلى Netlify. سيُنشأ توقيع الرفع في الخادم، ولا يظهر API Secret داخل المتصفح.
4. حسابات الاختبار والصلاحياتأضيفي حساب Instagram الاحترافي كحساب اختبار/دور في التطبيق، وامنحي صلاحيات النشر والتعليقات والرسائل والتحليلات. صلاحية التحليلات هي instagram_business_manage_insights. استخدام حسابات خارج أدوار التطبيق قد يتطلب Advanced Access ومراجعة Meta.
5. إعادة الربط بعد إضافة صلاحيات جديدةإذا كان الحساب مربوطاً قبل إضافة صلاحية التحليلات، افصليه ثم أعيدي ربطه حتى يطلب Instagram الموافقات الجديدة ويصدر رمزاً بالصلاحيات المحدّثة.
مهم: الربط والتحليلات يقرآن بيانات الحساب فقط. لا تنشر الصفحة منشورات أو Reels ولا ترسل رسائل أو ترد على تعليقات تلقائياً. كل نشر أو رد مستقبلي سيبقى داخل مسار مراجعة المالكة أولاً.

ما الذي سيأتي بعد نجاح الربط؟

بعد إثبات الاتصال، تكون المرحلة التالية هي تجهيز مسودات المحتوى وتقويم النشر، ثم بناء إجراءات النشر والتعليقات والرسائل عبر صلاحيات Meta الفعلية. لا تُفعّل أي عملية خارجية قبل إظهار معاينتها واعتمادها.
